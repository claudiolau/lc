# dev portfolio

- **Framework**: [Next.js](https://nextjs.org/)
- **Deployment**: [Vercel](https://vercel.com)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)

## Overview

- `app/components/*` - The different components the whole site uses
- `app/writing/*` - History of thoughts and journaling
- `app/public/*` - Static assets including fonts and images.
- `app.api/*` - API route handlers and server-side endpoints

## Running Locally

This application requires Node version: 16.3.6

```bash
bun install
bun run dev
```
